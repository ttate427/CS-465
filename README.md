In this course, I used Express, HTML, Handlebars, and JavaScript for the customer-facing website. I used Angular to create the admin single-page application (SPA). The SPA allowed pages to update without completely reloading and used separate components for viewing, adding, and editing trips.
The backend used MongoDB, a NoSQL database. MongoDB stores data in documents similar to JSON, which made it easy to store and access trip information. It also works well with the other technologies in the MEAN stack.
JavaScript is a programming language, while JSON is a format used to store and exchange data. JSON helped connect the frontend and backend because the API could send trip data that Angular could receive and display.
I refactored the project by moving trip data from a JSON file into MongoDB and creating a REST API. I also separated the code into routes, controllers, models, components, and services. Reusable components made the application easier to organize, update, and maintain.
I learned how API methods and endpoints work. GET retrieves data, POST adds data, PUT updates data, and DELETE removes data. I tested the API and Angular application using Postman and the browser to make sure data was being sent and received correctly.
Security added another step to testing because protected features required authentication. I added login authentication using a JSON Web Token (JWT), which helped protect the admin features and API endpoints from unauthorized users.
This course helped me understand how the frontend, backend, database, and API work together in a full stack application. I gained experience with JavaScript, Node.js, Express, Angular, MongoDB, REST APIs, Git, GitHub, authentication, testing, and debugging.
These skills will help me work toward a career in software development. The Travlr Getaways project also gives me a full stack application that I can include in my portfolio and show to future employers.
